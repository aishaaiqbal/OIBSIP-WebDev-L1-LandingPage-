# 🍔 Burger House

A modern and responsive burger restaurant landing page built using HTML and CSS.

## 🌟 Features

- Responsive navigation bar
- Fixed navbar
- Attractive hero section
- About section
- Contact section
- Contact form
- Smooth section navigation
- Hover effects
- CSS animations
- Responsive design for mobile devices
- Footer with social links

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts

## 📁 Project Structure

Burger-House/
│
├── index.html
├── style.css
├── burgerimg.jpg
└── README.md

## 🎨 Design

The website uses a dark brown, black, white, and golden color palette to create a warm, modern, and appealing restaurant aesthetic.

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## 📸 Preview

A responsive burger restaurant landing page featuring a hero section, About section, Contact section, and footer.
