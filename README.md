🍔 Burger House

A modern and responsive burger restaurant landing page built with HTML and CSS.
The website features a clean dark-themed design with a warm golden color palette.

✨ Features
🍔 Attractive hero section
📌 Fixed navigation bar
📖 About section
📞 Contact section
📝 Contact form
🔗 Navigation between sections
✨ Hover effects
🎬 CSS animations
📱 Responsive design for mobile devices
🦶 Footer with social links and policies
🛠️ Technologies Used
HTML5
CSS3
Google Fonts
🎨 Design

The website uses a dark brown, black, white, and golden color combination to create a modern and warm restaurant-style aesthetic.
